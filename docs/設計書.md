# インターン管理アプリ 設計ドキュメント

---

## 概要

サマーインターンの締切・日程・企業情報を一元管理するWebアプリ。
カレンダーで日程を把握し、企業ごとのメモ・アカウント情報・ファイルも管理できる。

---

## 技術スタック

| 用途 | 採用技術 | 理由 |
|---|---|---|
| フレームワーク | Next.js 15（App Router）+ TypeScript | SSR・API Routes・Server Actions が使える |
| スタイリング | Tailwind CSS + shadcn/ui | ユーティリティ + 高品質UIコンポーネント |
| カレンダー | FullCalendar（@fullcalendar/react） | 見た目が良い・月/リストビュー・期間バー対応 |
| データ | JSONファイル + Server Actions | ファイル直接編集も可・サーバー側でread/write |

## データ構造

### `data/categories.json`

```json
[
  { "id": "finance", "label": "金融", "color": "#3b82f6" },
  { "id": "sier",    "label": "SIer", "color": "#8b5cf6" }
]
```

### `data/companies.json`

```json
[
  {
    "id": "example",
    "name": "サンプル企業",
    "category": "finance",
    "color": "#e74c3c",
    "notes": "## メモ\n...",
    "url": "https://...",
    "mypageUrl": "https://...",
    "loginId": "",
    "readmePath": "finance/example/README.md",
    "trackingState": "active",
    "primaryProcessId": "proc-example-intern"
  }
]
```

`readmePath` を設定すると、`RECRUIT_ROOT` 配下の Markdown ファイルをメモとして読み込む。

### `data/processes.json`

企業ごとに複数の選考プロセスを保持する。企業によって異なる選考フローは `steps` の
追加・並べ替えで表現し、`currentStepId` で現在地を明示する。

```json
[
  {
    "id": "proc-example-intern",
    "companyId": "example",
    "name": "サマーインターン",
    "kind": "internship",
    "status": "active",
    "result": "accepted",
    "currentStepId": "step-example-intern",
    "steps": [
      {
        "id": "step-example-intern",
        "label": "インターン参加",
        "kind": "internship",
        "state": "scheduled",
        "result": "accepted",
        "order": 0
      }
    ]
  }
]
```

- `kind`: `internship` / `early_selection` / `main_selection` / `event` / `other`
- `status`: `considering` / `active` / `completed` / `closed`
- `result`: `none` / `accepted` / `offered` / `rejected` / `withdrawn`
- ステップの `state`: `not_started` / `action_required` / `scheduled` / `submitted` /
  `awaiting_result` / `completed` / `skipped` / `cancelled`
- ステップの `result`: `none` / `passed` / `failed` / `accepted` / `withdrawn`

### `data/events.json`

```json
[
  {
    "id": "example-deadline",
    "companyId": "example",
    "title": "ES締切",
    "type": "deadline",
    "start": "2026-06-01",
    "end": "2026-06-01",
    "state": "todo",
    "processId": "proc-example-intern",
    "stepId": "step-example-es",
    "note": ""
  }
]
```

**type の種類**

| type | 説明 | カレンダー表示 |
|---|---|---|
| `deadline` | 応募・ES・テスト締切 | 単日・警告アイコン |
| `internship` | インターン実施期間 | 期間バー |
| `selection` | 面接・GD等の選考 | 単日 |
| `event` | 説明会・セミナー | 単日 |

**state の種類**

| state | 説明 |
|---|---|
| `todo` | 対応が必要 |
| `scheduled` | 日程が確定した予定 |
| `done` | 完了 |
| `cancelled` | 中止 |

予定の状態と選考結果は分離する。結果は `processes.json` のプロセスまたはステップに保持し、
予定には必要に応じて `processId` と `stepId` を紐づける。

## 主要機能

### カレンダー
- 月ビュー・リストビュー切り替え
- イベントを企業カラーで色分け
- 締切は単日マーカー、インターン期間はバー表示
- クリックでステータス変更・編集・削除

### バッティング検出
- internship 同士の期間重複を自動検出してサイドバーに警告表示

### 締切カウントダウン
- サイドバーに直近の締切を一覧表示（3日以内は赤、7日以内はオレンジ）

### 企業メモ
- Markdown で記述・プレビュー表示
- `readmePath` 設定時は外部ディレクトリの Markdown と同期

### アカウント情報管理
- マイページ URL・ログインID を企業ごとに保存
- ログインID はワンクリックコピー対応

### ファイルブラウザ
- 企業フォルダ直下の通常ファイルを一覧表示・ブラウザで表示またはダウンロード
- 登録外パス、隠しファイル、シンボリックリンク、`RECRUIT_ROOT` 外へのアクセスは拒否

### 業界カテゴリ管理
- カテゴリを動的に追加（名前・カラー設定）
